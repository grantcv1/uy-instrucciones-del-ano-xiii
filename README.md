# The Instrucciones del Año XIII in Akoma Ntoso

The instructions José Artigas gave on April 13, 1813 to the deputies of the Banda Oriental for the Assembly in Buenos Aires, in Akoma Ntoso XML, with a CSS stylesheet that renders them. It was generated by Claude for Grant Vergottini.

The text is in Spanish, with no translation.

## Files

| File | Purpose |
| --- | --- |
| `instrucciones-del-ano-xiii.xml` | The Akoma Ntoso document |
| `instrucciones-del-ano-xiii.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page for GitHub Pages |

To view the document locally, keep the XML and CSS files in the same folder and open the XML in a browser.

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1). The namespace is `http://docs.oasis-open.org/legaldocml/ns/akn/3.0`, with `version="3.1"` on the root element.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 cs01 schema.
- **Document type:** The Instrucciones are a mandate to deputies, not a law, so this is a `<doc name="instrucciones">` and not an `<act>`.
- **Structure:** The twenty articles are `<article>` elements in `<mainBody>`. The first has no number in the source, so it has no `<num>`. Its `eId` is `art_1`.
- **Abbreviations:** Raised letters, as in `Primeram.<sup>te</sup>`, are `<sup>` elements.
- **Highlight:** The words "la independencia absoluta" are in `<span class="landmark">`. The emphasis is editorial and is not in the source.
- **Identifiers:** Every element with an `eId` also has a `GUID`. Text-level `<p>` elements have neither.

## Text

The text is N.° 104 of *Archivo Artigas*, tomo XI, pages 103 to 104: "Copia autenticada por Artigas de las Instrucciones", held by the Museo Histórico Nacional, Colección de Manuscritos. It was read from the page images and follows that printing, including its spelling, capitals and punctuation, such as "denominante", "en tresi", "Vruguay" and "Taquarembó". Words broken across lines are rejoined, and the folio marks are left out. The ending "Es Copia" is in the source.

Editions of this text differ, and many online versions modernize the spelling. *Archivo Artigas* prints other versions alongside this one, including the copy sent to Paraguay (N.° 105), which reads "Santa Teresa" where this one reads "Santa Tecla" in Article 9, and it lists more. The reading here is one copy, not a critical text.
